# ComplexWithTemplates2

A custom templated Complex number implementation in modern C++20.

## Features
- forwarding constructors
- CTAD
- constrained templates
- move semantics
- ObjectStorage abstraction
- polymorphic printing
- exception-aware operations

## Build
Requires:
- C++20
- clang++ or g++

Example:
g++ -std=c++20 main.cpp
